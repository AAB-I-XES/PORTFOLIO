# Google Search Console Guide

## 1. Open Google Search Console
1. Sign in to Google Search Console at https://search.google.com/search-console/
2. Add a property for the live domain: https://dibrab.vercel.app/
3. Choose the verification method offered by Google and complete it for the Vercel domain

## 2. Verify ownership
Use one of the approved options for a Vercel-hosted site, such as:
- DNS verification
- HTML file verification
- Google Analytics or Tag Manager if already connected

## 3. Submit the sitemap
Submit the following URL once the site is live:
- https://dibrab.vercel.app/sitemap.xml

## 4. Inspect the homepage
After verification, check the live URL:
- https://dibrab.vercel.app/

Look for:
- page indexing status
- canonical URL correctness
- whether the page is recognized with the expected title and description

## 5. Inspect important project and portfolio URLs
Use Search Console to inspect the homepage and any other public URLs that are added later. For this site, the primary public URL is the homepage because the current architecture is a single-page portfolio.

## 6. Request indexing where appropriate
Use the URL inspection tool for:
- homepage
- live portfolio root URL
- any extra static pages added in the future

## 7. Monitor indexing and search performance
Watch for:
- indexing coverage status
- Core Web Vitals
- mobile usability issues
- search query impressions and click trends

## Important note
Code can improve technical readiness, but it cannot guarantee that Google will index or rank a page. Indexing depends on crawlability, content quality, link signals, and Google’s evaluation of the live site.
