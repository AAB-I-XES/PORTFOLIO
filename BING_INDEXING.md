# Bing Webmaster Tools Guide

## 1. Add the website to Bing Webmaster Tools
1. Visit https://www.bing.com/webmasters/
2. Sign in with a Microsoft account
3. Add the website as a property using https://dibrab.vercel.app/

## 2. Verify ownership
Use one of the supported verification methods offered by Bing, such as:
- DNS verification
- HTML file verification
- XML file verification
- meta tag verification
- importing a verified Google Search Console property

## 3. Submit the sitemap
Submit the sitemap here:
- https://dibrab.vercel.app/sitemap.xml

## 4. Inspect URLs
After verification, inspect:
- the homepage
- the root page for canonical and title accuracy
- any public URLs later added to the portfolio

## 5. Monitor crawl and indexing
Review:
- sitemap status
- crawl errors
- page indexing information
- search performance data

## 6. Search performance monitoring
Track:
- clicks
- impressions
- top queries
- pages that receive traffic

## IndexNow evaluation
IndexNow is optional for a small portfolio site. It can be useful if the site changes frequently and you want to notify search engines quickly, but it is not required for a simple static portfolio. If you later implement it, only submit changed URLs and avoid excessive or junk submissions.
